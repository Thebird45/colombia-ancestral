# Viajes Colombia Ancestral · Landing page

Desierto de la Tatacoa con observación de estrellas y excursión de 2 días a San Agustín.

**Demo en vivo:** https://thebird45.github.io/colombia-ancestral/

## Diseño
Nocturno: cielo estrellado animado en `<canvas>`, acentos dorados y tipografía Cinzel.

## Detalles técnicos
- HTML, CSS y JavaScript puro: sin frameworks ni dependencias, un solo archivo.
- Totalmente responsive (escritorio, tablet y celular).
- Estrellas animadas con Canvas · header que cambia al hacer scroll · mosaico de fotos · video de fondo.
- Botón de reserva directo a WhatsApp.

## Verlo localmente
Abre `index.html` en cualquier navegador.
